# Portafolio Personal - San7imo Universe 🚀

Un portafolio interactivo y dinámico desarrollado con React y TypeScript que presenta mi trabajo y habilidades a través de una experiencia inmersiva inspirada en el espacio.

![Logo San7imo](/public/assets/img/logoN.webp)

## 🌌 Características

- **Diseño Interactivo**: Interfaz inspirada en el espacio con animaciones y efectos visuales
- **Secciones Principales**:
  - 🛸 Technologies: Showcase de tecnologías dominadas
  - 🌍 Projects: Timeline interactivo de proyectos
  - 🌙 Skills: Exploración de soft skills en superficie lunar
  - 📡 Contact: Sistema de contacto con animaciones
- **IA Assistant**: Chatbot integrado para responder preguntas sobre mi perfil
- **Responsive Design**: Adaptable a todos los dispositivos
- **Efectos Visuales**: Animaciones con Framer Motion y efectos de partículas

## 🛠️ Tecnologías

- React 19.1.0
- TypeScript
- Vite
- TailwindCSS
- Framer Motion
- Google AI (Gemini)
- React Router DOM
- React Markdown
- React Icons
- Lucide React

## 📦 Instalación

1. Clona el repositorio:
```bash
git clone https://github.com/yourusername/my-portfolio.git
```

2. Instala las dependencias:
```bash
cd my-portfolio
npm install
```

3. Crea un archivo `.env` con las siguientes variables:
```env
VITE_GOOGLE_API_KEY=tu_api_key
```

4. Inicia el servidor de desarrollo:
```bash
npm run dev
```

## 🚀 Despliegue

Para construir el proyecto para producción:

```bash
npm run build
```
